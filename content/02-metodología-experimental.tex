\chapter{Metodología}
El método de trabajo se enfocó en la simulación de escenarios de error operativo dentro de la base de datos previamente construida. En primer lugar, se definieron los casos de prueba basados en las reglas de negocio de Import Tech S.A.S., categorizándolos en validaciones de entidad, dominio y de referencia. Posteriormente, se redactaron y ejecutaron \textbf{instrucciones SQL (DML)} diseñadas intencionalmente para infringir estas reglas, tales como inserciones de datos huérfanos, eliminación de registros vinculados y duplicidad de identificadores. Finalmente, se recopilaron las advertencias y bloqueos generados por el motor de la base de datos para contrastarlos con los resultados esperados.
