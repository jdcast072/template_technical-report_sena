\section{Comandos DML (actualización, inserción y eliminación)}

\subsection{Creación de las colecciones}

Se creó la base de datos \codigo{j-mundial} y sus colecciones asociadas a las hojas del archivo \codigo{Datafile.xlsx}: \codigo{Matchs}, \codigo{Players} y \codigo{Teams}. El siguiente bloque selecciona la base de datos y crea las colecciones.
\begin{lstlisting}
    use j-mundial;
    db.CreateCollection("Matchs");
    db.CreateCollection("Players");
    db.CreateCollection("Teams");
  // Salida de comando
\end{lstlisting}

\subsection{Registrar información de prueba}
Se registró información de prueba en las colecciones definidas mediante scripts de JavaScript. Por su extensión, se presenta un resumen con los equipos solicitados, los jugadores y un partido de ejemplo:

\begin{enumerate}
    \item Creación de los equipos de fútbol:
    Este comando inserta los documentos correspondientes a los equipos de Colombia y Japón, junto con el resto de registros representados por puntos suspensivos.
    \begin{lstlisting}
db.Teams.insertMany([
    {...},
    {
    "id": 5,
    "abbreviation": "col",
    "country": "Colombia",
    "Confederation": "CONMEBOL"
    },{
    "id": 15,
    "abbreviation": "jpn",
    "country": "Japan",
    "Confederation": "AFC"
  },
  {...}
])
// Salida de comando
    \end{lstlisting}
    \item Creación de los jugadores
    El siguiente script inserta masivamente los jugadores de la selección de Colombia.
    \input{content/scripts/01-insert-players.tex}
    \item Creación del partido entre los equipos asociados, junto con la fecha de encuentro:
    Este comando registra un partido entre Colombia y Japón con su fecha y hora de encuentro.
    \begin{lstlisting}
db.Matchs.insertOne({
    "Match": 16,
    "Team 1": "Colombia",
    "Team 2": "Japan",
    "Date": "2018-07-11",
    "Time": "12:00:00"
  });
// Salida de comando
    \end{lstlisting}
    
\end{enumerate}

\subsection{Eliminación de un partido del registro}
Se localiza el partido 56, se elimina mediante sus equipos y se ejecuta una nueva consulta para comprobar el resultado.
\begin{lstlisting}
    db.Matchs.find({Match:56});
  // Salida de comando
[
  {
    _id: ObjectId('6ab40a56ca397faec6a26168'),
    Match: 56,
    'Team 1': 'Colombia',
    'Team 2': 'England',
    Date: '2018-08-20',
    Time: '18:00:00'
  }
]
db.Matchs.deleteOne({ "Team 1": "Colombia", "Team 2": "England" });
// Salida de comando
 db.Matchs.find({Match:56});
// Salida de comando
\end{lstlisting}
