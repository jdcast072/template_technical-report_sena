\chapter{Conclusiones}
\begin{itemize}
    \item Se logró diseñar e implementar íntegramente el modelo físico relacional para el sistema de información de Importech S.A., garantizando un control optimizado y eficiente sobre sus operaciones comerciales \supercite{SENA}.
    \item La aplicación metódica del modelado conceptual y lógico, estructurado hasta la tercera forma normal (3NF), evitó anomalías de actualización y redundancias en los datos \supercite{codd1970relational}.
    \item El despliegue a través del lenguaje DDL permitió definir una arquitectura robusta, la cual asegura la consistencia de los datos mediante el uso estricto de llaves primarias (\colorbox{gray!20}{\textcolor{lineText}{\texttt{PRIMARY KEY}}}) y foráneas (\colorbox{gray!20}{\textcolor{lineText}{\texttt{FOREIGN KEY}}}) \supercite{silberschatz2020}.
    \item Las transacciones ejecutadas mediante el lenguaje DML demostraron que la base de datos centraliza los flujos de información de manera estable. Esto confirma que el sistema resultante sirve como una base tecnológica escalable, ideal para facilitar la toma de decisiones estratégicas dentro de la organización.
\end{itemize}
