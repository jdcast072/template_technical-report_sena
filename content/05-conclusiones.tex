\chapter{Conclusiones}

A partir de las pruebas de validación ejecutadas sobre la base de datos, se establecen las siguientes conclusiones:

\begin{enumerate}
    \item Se comprobó exitosamente que el diseño físico de la base de datos de Import Tech S.A.S. rechaza cualquier operación DML que vulnere la integridad referencial, protegiendo con rigurosidad las relaciones cardinales entre ventas, clientes, productos y proveedores \supercite{dominguez2021}.
    \item Se demostró que las restricciones de entidad y de dominio operan como un mecanismo de defensa estructurado ante fallos operativos, garantizando la unicidad de los datos clave y la obligatoriedad de la información \supercite{dominguez2021}.
    \item Se valida de forma concluyente que la Base de Datos Relacional de Import Tech S.A.S. cumple con los requisitos técnicos de diseño, configurándose como un sistema de almacenamiento seguro, consistente y preparado para controlar la lógica transaccional de la compañía \supercite{cobo2007}.
\end{enumerate}
