\chapter{Resumen}
El presente informe detallará el proceso del diseño y estructuración del \textbf{modelo físico relacional} para la implementación de la base de datos a la empresa comercializadora \textbf{Import Tech S.A.S} \supercite{SENA}. Según la necesidad de automatizar y optimizar el control de inventarios, registro de ventas y productos para clientes y proveedores, se realizará en la metodología el uso de los lenguajes \textbf{SQL (Structured Query Language)} y sus abreviados de ejecución de sentencias: \textbf{Definición de datos (DDL)} y \textbf{manipulación de datos (DDL/DML)}. Como resultado, se consolidó una base de datos normalizada y robusta que garantiza la integridad referencial a través de llaves primarias y foráneas. Concluyendo que la arquitectura implementada centraliza las operaciones comerciales de manera eficiente, reduciendo márgenes de error y sirviendo como base tecnológica escalable para la toma de decisiones estratégicas de la organización.
\begin{itemize}
    \item \textbf{Palabras clave}: Sistema de información, Base de datos relacional, Lenguaje de definición de datos (DDL), Lenguaje de manipulación de datos (DML), Importech S.A.S.
\end{itemize}
