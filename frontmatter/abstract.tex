\chapter{Resumen}
Este documento técnico se presenta el diseño, desarrollo e implementación de una API RESTful desarrolladad para la gestión de inventario de la tienda de tecnología Revival Tech. Al haber tenido la necesidad de almacenar información de tecnológica con atributos altamente variables, se optó por una arquitectura de base de datos \textbf{NoSQL} usando \codigo{MongoDB}. El backend fue construido con el entorno \codigo{\textbf{Node.js}} empleando el framework \codigo{\textbf{Express}} para el enrutamiento. Para optimizar el rendimiento y la seguridad del sistema, se integraron dependencias clave: \codigo{\textbf{Mongoose}} para el modelado de datos y validación de esquemas; \codigo{\textbf{dotenv}} para la protección de credenciales de entorno; \codigo{\textbf{morgan}} para el monitoreo y registro (logging) de las peticiones HTTP; y \codigo{\textbf{body-parser}} para la correcta extracción y transformación de los datos entrantes en las solicitudes. Se detallan a continuación los objetivos, procedimientos y la evidencia de ejecución del sistema.
