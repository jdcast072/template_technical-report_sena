\chapter{Resumen}
El presente informe técnico documenta el diseño y la ejecución de pruebas de validación sobre el modelo relacional de la base de datos de Import Tech S.A.S.. Con el propósito de asegurar la integridad de los datos y el correcto funcionamiento del sistema comercial, se aplicaron sentencias del SQL enfocado al \textbf{Lenguaje de Manipulación de Datos (DML)} orientadas a forzar violaciones de restricciones de llave primaria, foránea y de dominio. Como resultado, se demostró que el \textbf{Sistema de Gestión de Bases de Datos (SGBD)} bloquea anomalías y protege la coherencia transaccional ante errores de inserción o eliminación. Concluyendo que el modelo físico es altamente robusto y consistente frente a fallas operativas que se puedan dar en producción.
\begin{itemize}
    \item \textbf{Palabras clave}: Pruebas de validación, Integridad relacional, Restricciones SQL, Llaves foráneas, Import Tech S.A.S.
\end{itemize}
